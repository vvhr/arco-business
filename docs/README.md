`Arco Business Docs` 是 Acro Business 的独立 Vite 文档站，用于维护组件介绍、快速开始、扩展指南、在线示例、API 表格和源码预览。
文档站服务于组件库维护者和业务使用者。组件库源码仍位于根目录 [src](../src)，文档站通过别名引用组件库源码和示例代码。
